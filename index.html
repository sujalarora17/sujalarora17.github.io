Engineering depth

Two systems projects in C++

These are not design tools, but they show I can build from scratch and test how fast things run.

Redis Clone

A Redis-style database I wrote from scratch in C++. It handles many clients at once over TCP and speaks Redis's own protocol (RESP2), so the real redis-cli works with it. It supports O(1) LRU eviction and expiring keys. I measured about 5K requests per second with 20+ clients.

Mini Search Engine

A search engine in C++ that indexes 1,000+ documents and 20K+ terms. It supports AND/OR search, exact phrase search and TF-IDF ranking, and answers in under 25 ms per query.

How I like to work

From a problem to a tool people use

The steps I follow, and where I have already done each one.

  1. Find the real problem

    Watch how the task is done, ask what is slow or annoying, and look past the complaint to the cause.

    Done in: Financial Anomaly Detection

  2. Try the options

    Test a few approaches on real samples before choosing one.

    Done in: comparing 4 OCR engines on 500+ samples

  3. Build it simple

    Keep the tool easy to use, handle failures gracefully, and put it online so it is one link away.

    Done in: Multi-Agent Data Analyst

  4. Learn from real use

    Track what users correct, find where the tool struggles, and write it up in plain language.

    Done in: NIT Calicut correction logs
